发送消息

P_SEND_MSG

把消息发给 Broker。Broker 落盘后立即返回 P_CONFIRM_MSG； 消息是否被消费成功由消费者的 ACK 单独决定。

消息分类，消费者按 Topic 订阅。

二级过滤，消费者可用 * 订阅全部。

填入示例：
⌘ / Ctrl + Enter 快速发送

消费者

joinGroup → groupSubscribe

每个消费者都是真实 TCP 客户端。同一组内共享位点（负载均衡），不同组各自收到全量消息； Tag 是消费者级的，同组可以订阅不同 Tag。

相同组名的消费者分摊消息。

要订阅的主题。

逗号分隔；* 表示全部。

创建后立即订阅并开始接收消息

消费者组 / 位点

offset · in-flight · tags

组位点是"组内已确认到哪条消息"的水位线；在途表示已推送但还没 ACK。点击行查看消费者与 Tag 详情。

Broker 内存消息

messageMap

最近的消息，按 ID 倒序。点击任意一行查看完整内容；已进入死信的消息会从内存移除。

死信队列

重放回原组

投递次数耗尽或业务主动拒绝后的消息。点击行查看详情，或直接点「重放」重新投递给原消费组。

测试

自检直接跑在运行中的 Broker 上；Maven 测试在仓库根目录执行，日志实时回显。
